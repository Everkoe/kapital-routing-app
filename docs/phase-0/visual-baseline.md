# Matriz de referencia visual

Las capturas se guardan localmente en `artifacts/visual-baseline/` y están
ignoradas por Git para evitar incluir datos personales. Antes de capturar, usar
una base anonimizada o cubrir nombres, DNI, teléfonos, placas y documentos.

Convención de nombre:

`<rol>--<vista>--<tema>--<viewport>.png`

| Rol | Vistas mínimas | Temas | Viewports |
|---|---|---|---|
| Administración | Dashboard, usuarios, flota, modal conductor, documento | Claro/Oscuro | 1440x900, 390x844 |
| Programador | Tablero vacío, rutas generadas, mapa, Copilot | Claro/Oscuro | 1440x900, 390x844 |
| Gerente | Sin datos, dashboard completo, tabla | Claro/Oscuro | 1440x900, 390x844 |
| Cliente | Dashboard, detalle conductor | Claro/Oscuro | 1440x900, 390x844 |
| Conductor | Onboarding, observados, rutas, perfil, SOS | Claro/Oscuro | 1440x900, 390x844 |

En cada comparación revisar tipografía, espaciado, colores, iconos, estados,
modales, scroll, foco de teclado y ausencia de desbordamiento horizontal.
